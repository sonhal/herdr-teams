# Listing draft

**Name:** herdr teams

**Repository:** https://github.com/sonhal/herdr-teams

**Install:** `herdr plugin install sonhal/herdr-teams`

Run persistent teams of coding agents in herdr. Coordinate through a shared
board, direct messages, plan reviews and quality gates. Give parallel writers
isolated worktrees and supervise progress without automatic restarts.

Requires Node.js 20 or later and herdr 0.9.5 or later on Linux or macOS.
Codex, Claude Code, pi and OpenCode adapters are included. Codex-only contract
tests run in CI; other agent runtimes and real herdr sessions remain manual
validation. OpenCode thinking effort is configured natively.

The listing is prepared for submission after the feature PRs land. It has not
been published. No credentials are bundled; agents use their normal shell setup.
